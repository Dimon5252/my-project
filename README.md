# Хрестики-нулики

Проста консольна гра «Хрестики-нулики», написана мовою Python.

## Як запустити

1. Встановіть Python.
2. Завантажте файл `main.py`.
3. Відкрийте термінал у папці з файлом.
4. Запустіть команду:

```bash
python main.py
```

## Правила

- Грають два гравці: X та O.
- Гравці ходять по черзі.
- Щоб зробити хід, потрібно ввести число від 1 до 9.
- Перемагає той, хто першим поставить три свої символи в ряд.
- Якщо всі клітинки заповнені, а переможця немає, це нічия.
